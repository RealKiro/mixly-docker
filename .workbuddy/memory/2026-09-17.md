## mixly-docker 仓库名大小写报错修复

- 现象：NAS（群晖 Container Manager）运行时报 "repository name must be lowercase"。
- 根因：NAS 上导入的项目还是旧版 compose（`ghcr.io/RealKiro/...` 大写）；仓库侧 compose 已在 8fd1b00 改为小写，但 Container Manager 导入的是快照，不会随仓库更新。
- 仓库侧加固（提交 fa36d2e，已推送）：
  - ci.yml：push-images / manifest 两 job 各加"镜像名转小写"步骤（`${GITHUB_REPOSITORY_OWNER,,}` 写入 GITHUB_ENV 覆盖 workflow 级 GHCR_IMAGE），否则打 v* 标签推送时必炸。
  - build-push.sh：GHCR_USER / DOCKERHUB_USER 用 tr 强制转小写。
  - README-docker.md：两处 `ghcr.io/RealKiro/...` 示例改小写。
- 经验：GitHub 表达式没有 lower()；ripgrep 默认跳过 .github 隐藏目录，查镜像名引用时要单独 glob .github。Docker 仓库名必须全小写，`github.repository_owner`（RealKiro）是常见大写来源。
- 待办：用户需在 NAS 上把项目 compose 的 image 行改小写后重新构建；GHCR 包若为 Private，NAS 拉取需先设 Public 或 docker login。
